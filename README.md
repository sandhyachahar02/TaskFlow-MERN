# 🚀 TaskFlow - MERN Stack Task Management System

TaskFlow is a modern full-stack task management application built using the MERN Stack. It helps users organize their daily tasks, manage categories, track progress through an interactive dashboard, and securely manage their accounts.

---

## ✨ Features

### 🔐 Authentication
- User Registration
- Secure Login
- JWT Authentication
- Protected Routes
- Logout
- Change Password

### 📋 Task Management
- Create Tasks
- Edit Tasks
- Delete Tasks
- Mark Complete / Reopen
- Search Tasks
- Filter by
  - Status
  - Priority
  - Category
- Due Dates
- Task Notes
- Estimated Time

### 📂 Category Management
- Create Categories
- Edit Categories
- Delete Categories
- Category-wise Organization

### 📊 Dashboard
- Statistics Cards
- Weekly Progress Chart
- Category Distribution Chart
- Recent Tasks
- Quick Filters

### ⚙️ Settings
- Update Profile
- Change Password

### 🎨 UI / UX
- Responsive Design
- Mobile Sidebar
- Skeleton Loaders
- Custom Confirmation Modal
- Notification Dropdown
- Professional Dashboard UI

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/sandhyachahar02/TaskFlow-MERN.git
```

## Backend

```bash
cd Backend
npm install
npm run dev
```

## Frontend

```bash
cd Frontend
npm install
npm run dev
```

---

# 🔑 Environment Variables

## Backend (.env)

```env
PORT=8000
MONGO_URL=YOUR_MONGODB_URL
JWT_SECRET=YOUR_SECRET_KEY
```

## Frontend (.env)

```env
VITE_API_URL=http://localhost:8000/api
```
